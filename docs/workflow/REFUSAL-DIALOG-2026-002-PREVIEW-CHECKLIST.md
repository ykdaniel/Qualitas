- 3 個測試帳號（rd2_reviewer、rd2_inspector、rd2_noproject）共用同一個密碼，只存在這次的執行目錄，不會出現在對話裡。要換帳號請告訴我，我幫你登入。

  1. 只跳出一個彈窗，按「我知道了」、× 或 Esc 會關閉。
  2. 彈窗關掉後，表單還開著，你填的內容都還在。
  3. 頁面頂部沒有紅色橫幅。

## A. 422 欄位錯誤逐欄條列（D1），以及 4xx 的「內容已保留」（D3）
1. 稽核 → 打開 **RD3-AUD-000001** → 把 Audit End Date 改成 **2026/10/10**（早於開始日 2026/10/20）。
2. 右上角先出現黃色警告（前端的提醒，本來就有）。不用理會，直接按「儲存草稿」。
3. 應該跳出「**無法儲存**」：
   - 第一行：有欄位內容不正確，請修正後再儲存：
   - 條列：• 結束日期：早於開始日期
   - 最後一行：您填寫的內容都已保留，修正後再按儲存即可。

## B. 紀錄已鎖定（RECORD_LOCKED）
4. PQP → 打開 **RD3-PQP-000001**（已核准）→ 把主旨改成任何文字 → 按「儲存」。
5. 應該跳出「無法儲存：PQP RD3-PQP-000001 的狀態為「Approved」，內容不能直接修改。如需修改，請用「Publish」建立新版次。」，最後一行**只有**「您填寫的內容都已保留。」，沒有「修正後再按儲存」（使用者 2026-10-14 選 (a)）。

## C. 不允許的狀態轉換（INVALID_TRANSITION）：要在兩個分頁操作
6. 會議記錄 → 打開 **RD3-MOM-000001**（Draft），先不要存檔。
7. 另開一個分頁，到同一筆會議記錄，把狀態改成 **Published** 並存檔。也可以請我在背景幫你做這一步。
8. 回到第一個分頁，改一下主題 → 按「儲存」。
9. 應該跳出「無法儲存：會議記錄 不能從「Published」改為「Draft」。」，最後一行是「內容已保留」。

## D. 資料已被別人修改（VERSION_CONFLICT）：要在兩個分頁操作
10. ITR → 打開 **RD2-ITR-000001**，先不要存檔。
11. 另開一個分頁，在同一筆 ITR 改備註並存檔。也可以請我在背景幫你做。
12. 回到第一個分頁按「儲存」。
13. 應該跳出「無法儲存：ITR RD2-ITR-000001 已被其他人修改。請重新載入後再修改一次。」。
   - **沒有**「內容已保留」那一行：這種情況再存一次也不會成功（審查 R1 P2 的修正）。

## E. 沒有代碼的拒絕：中文通用句＋英文原文
14. ITR → 打開 **RD3-ITR-000001** → 按「Publish as next revision」→ 在確認視窗按「發佈」。
15. 應該跳出「無法儲存：系統拒絕了這個操作，原因如下：」，下面的框是英文原文「Cannot approve ITR without any linked checklists」，最後一行是「內容已保留」。

## F. PQP 和 Audit 的紅字（D2）
16. Audit：做完第 1–3 步後，精靈裡**沒有**紅框，只有彈窗。
17. PQP 保留的提醒（一）：PQP → 「新增品質計劃」→ 什麼都不填，直接按「Publish as next revision」。表單左下應該出現紅字「請先儲存再發布」，**不會**跳出彈窗。
18. PQP 保留的提醒（二）：PQP → 打開 **RD3-PQP-000002**（已核准）→ **其他欄位都不要改**，只在附件區上傳任意一個檔案 → 按「儲存」。
   - 記錄本身可以存（內容沒變），但已核准的 PQP 附件是鎖定的。
   - 表單內應該出現紅字「紀錄已保存，部分檔案操作未完成：上傳附件：This PQP is Approved…」，**不會**跳出彈窗，因為這不是被拒，而是部分完成。

## G. 需要換帳號的項目
19. **越權（SCOPE_FORBIDDEN）**：換成 **rd2_noproject**（有全部權限，但不屬於任何專案）→ 會議記錄 → 新增 → 填主題 → 儲存。
    - API 直接測過，會回「您目前沒有在任何專案中工作（不是專案成員，或登入時沒有選擇專案）。請重新登入並選擇專案。」。
    - 但前端可能會先擋住「新增」按鈕。如果按鈕本身不能按，那就是前端先擋下了，也算正常。
20. **沒有核准權限**：換成 **rd2_inspector**（沒有核准、結案權限）→ ITR → 打開 RD3-ITR-000001 → 如果看得到 Publish 就按。
    - 應該跳出「無法儲存」，內容是通用句加英文原文「Operation not permitted. Required: itr:approve:all」。
    - 如果看不到 Publish 按鈕，也算正常。

## H. 伺服器錯誤（5xx）的「內容已保留」：需要我配合
21. 隨便打開一筆可以存檔的紀錄（例如 RD3-MOM-000001，先在第 7 步前做），改一個欄位，**先不要存**，然後告訴我。
22. 我會把隔離後端停掉。這時按「儲存」，應該跳出「**儲存失敗**」：
    - 內容：伺服器處理時發生問題（HTTP 5xx）…
    - 最後一行：無法確認是否已儲存，您填寫的內容仍保留在這裡；請重新整理清單確認後再試。
23. 停掉後端，這個預覽就結束了。之後如果還要繼續看，我會重新開一個預覽並重建測試資料。
