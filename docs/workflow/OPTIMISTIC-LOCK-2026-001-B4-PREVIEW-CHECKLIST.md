# OPTIMISTIC-LOCK-2026-001 B4 預覽檢查表（ITR）

- **環境**：隔離環境（網址、帳號由開預覽的工作階段提供）。
- **做法**：兩個分頁 A、B，同一個帳號。ITR 視窗的版面和按鈕都不變。
- **每一組的步驟都一樣**：A、B 都打開同一筆 → A 先做 → B 再做 → B 應跳出「無法儲存：ITR …… 已被其他人修改」，並有「重新載入這筆」→ 按下並確認 → 視窗重新打開，顯示 A 的內容 → B 再做一次，應成功。

1. **存檔**：預覽用的 In Progress ITR，A 改備註後儲存；B 改主旨後儲存。
2. **發行**：同一筆 ITR，A 改一個欄位後儲存；B 按「發行」（核准）。
3. **撤回核准**：預覽用的 Approved ITR（OLB4-ITR-000002），A、B 都打開 → A 按「發行」（已核准的再發行一次，狀態仍是 Approved、版本變新）→ B 按撤回並填理由 → 409 →「重新載入這筆」→ B 再撤回一次 → 成功，變 In Progress。
   - 注意：如果 A 是直接**撤回**，B 再撤回時看到的是「不是 Approved，沒東西可撤回」，這是業務拒絕、不是版本衝突，所以沒有「重新載入這筆」，這是正常的。Raise NCR 也一樣：A 已開過 NCR 時，B 看到的是「已經有 NCR」。
4. **Checklist 面板**：
   - 打開預覽用 ITR 底下的 Checklist（Ongoing），A 在面板裡改一個項目的結果後按面板的儲存；B 也在同一個 Checklist 面板改了再存 → 409 →「重新載入這筆」→ 面板重新打開，顯示 A 的結果。
   - **Reopen 後再存**（B3a 移過來）：打開狀態為 Pass 的 Checklist（ITR 不是 Approved），按 Reopen → 變成 Ongoing → 改一個項目後按面板的儲存 → **成功**，不會撞 409。
5. **正常流程不受影響**：新建 ITR 並存檔（存完視窗不關，停在新建的這筆）→ 再改再存 → 成功；附件上傳、重試附件照舊。
