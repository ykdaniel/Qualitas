# REFUSAL-DIALOG-2026-003（2b）— 預覽試用清單（草稿）

> 2b-2 完成後補齊其他項目並開預覽（協調中心指示：只預覽一次）。下面先列協調中心要求的 ITR 兩組步驟。資料、帳號與網址開預覽時再補上。

## ITR-1. 發行或改狀態時，如果還有待上傳的檔案，會先擋下（Q1 (a)、P2-1 (a)）
1. ITR → 打開一筆 In Progress 的 ITR → 在「附件」區加入一個檔案，**先不要存**。
2. 按「Publish as next revision」：應該出現黃色提示「還有檔案變更尚未儲存。請先按『儲存』，再發行：ITR 核准後附件就會鎖定。」，**不會**發行，檔案仍在待上傳清單。
3. 把狀態下拉改成 Approved（或 Void），按「儲存」：應該出現黃色提示「還有檔案變更尚未儲存。請先用目前的狀態按『儲存』處理檔案，再把狀態改成核准或作廢…」，**不會**存檔。
4. 把狀態改回 In Progress，按「儲存」：檔案上傳，視窗照常關閉。重新打開後再發行，就可以正常發行。

## ITR-2. 部分檔案失敗後，可以只重試剩下的檔案
1. ITR → 打開一筆 In Progress 的 ITR → 改一個欄位，再加入兩類檔案，例如缺失照片和附件。
2. 用預覽工具讓其中一類上傳失敗（開預覽時說明做法），然後按「儲存」。
3. 應該看到：
   - 視窗**不關**。
   - 頂部出現琥珀色橫幅「已儲存……，但以下檔案未完成：上傳附件失敗（原因）」。
   - 成功的那一類已經不在待上傳清單；失敗的那一類還在。
4. 按橫幅上的「重試剩下的檔案」：只會重傳失敗的那一類，不會再寫一次記錄。成功後視窗關閉。
5. 新建 ITR 也照做一次：失敗時留在原視窗並顯示橫幅；重試成功後，切換到剛建立的那筆 ITR，並顯示「已建立 ITR …，現在可以連結檢查表」。
