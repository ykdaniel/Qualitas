## ITR-1. 發行或改狀態時，如果還有待上傳的檔案，會先擋下（已實測）
1. ITR → 打開 **RD3B-ITR-000002**（In Progress）→ 展開「附件」→ 上傳任意一個 PDF 或圖片，**先不要存**。
2. 按「Publish as next revision」：應該出現黃色提示「還有檔案變更尚未儲存。請先按『儲存』，再發行：ITR 核准後附件就會鎖定。」，**不會**發行。
3. 在「品質評估」把狀態改成「已核准」，按「儲存」：應該出現黃色提示「還有檔案變更尚未儲存。請先用目前的狀態按『儲存』處理檔案，再把狀態改成核准或作廢：之後附件就會鎖定。」，**不會**存檔。
4. 把狀態改回「進行中」，按「儲存」：檔案上傳，視窗關閉。

## ITR-2. 部分檔案失敗後，只重試剩下的檔案（已實測，用 RD3B-ITR-000001）
1. 打開 **RD3B-ITR-000002** → 展開「缺失照片／改善照片」→ 在缺失照片上傳一張圖片 → 展開「附件」→ 上傳一個伺服器不接受的檔案，例如 .json 或 .mov 影片。
   - 檔案選擇視窗如果把它濾掉，選「所有檔案」即可。
2. 按「儲存」，應該看到：
   - 視窗**不關**。
   - 頂部出現琥珀色橫幅「資料已保存，但以下步驟尚未完成：附件／上傳附件失敗（File type … is not allowed）」，附「重試剩餘檔案（不重寫資料）」按鈕。
   - 缺失照片已經上傳，不再標「NEW」。
3. 在「附件」把那個不接受的檔案用 × 移除，按「重試剩餘檔案」：只會重傳剩下的附件，不會再寫一次記錄，也不會再傳一次照片。成功後視窗關閉。
