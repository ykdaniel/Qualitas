# OPTIMISTIC-LOCK-2026-001 B3a 預覽檢查表

- **環境**：隔離環境（網址、帳號由開預覽的工作階段提供，密碼不寫在文件裡）。
- **做法**：兩個分頁 A、B，同一個帳號。

## 1. ITP 逐項套用（同一個視窗連續寫入，不會自己撞 409）
1. A 打開預覽用的 ITP，切到「檢驗計畫」分頁。
2. 連續編輯並套用 3 個項目（不要等上一個顯示完成，快速連按）→ 每一個都應該成功，不會跳出 409。
3. 再按「儲存」→ 成功（主檔和計畫依序寫入，計畫用主檔回傳的版本）。
4. B 先打開同一筆，A 存檔之後 B 再套用一個項目 → B 跳出 409 →「重新載入這筆」→ 確認 → 視窗重新打開，計畫分頁顯示 A 的內容。

## 2. ITPDetail 獨立頁的發行
（發行需要 ITP 是 Pending；預覽用的 ITP 已設成 Pending。Draft 不能直接發行，這是既有的流程規則。）
1. A 在網址列開 `/itp/olb3-itp-1`。
2. A 改一個項目後按「發行」→ 應成功（先寫版次與標題，再寫計畫，兩次寫入）。
3. B 先開同一頁；A 發行之後，B 按「儲存文件」→ 409 →「重新載入這筆」→ 確認 → 頁面重新載入，顯示 A 發行後的內容。

## 3. Checklist 範本
（Checklist 頁只列範本；ITR 名下實例的 Reopen 在 ITR 視窗的快照面板裡，已移到 B4。本頁 Reopen 的順修仍在程式裡，但從畫面點不到。）
1. A、B 都打開「Seeded checklist template」。
2. A 改「活動」後按 Save Template（編輯器關閉）。
3. B 按 Save Template → 409 →「重新載入這筆」→ 確認 → 編輯器重新打開，顯示 A 的活動 → 再存成功。

## 4. FAT：兩個視窗各自 409
1. A、B 都打開同一筆 FAT 的「編輯」；A 改地點後存檔；B 再存 → 409 →「重新載入這筆」→ 確認 → B 的**編輯**視窗重新打開，顯示 A 的地點。
2. A、B 都打開同一筆 FAT 的「明細」；A 改一列後存檔；B 再存 → 409 → 重新載入 → B 的**明細**視窗重新打開。

## 5. 補看（時間夠的話）
- **FollowUp**：兩個分頁同時改同一筆手動建立的事項 → 第二個存的出現 409，重新載入後看到對方的內容。
- **稽核範本**：A、B 都開同一個範本；A 存檔（編輯區不關）後再改再存，仍然成功；B 再存 → 409 → 重新載入後顯示 A 的版本。
- **Audit**：在精靈裡新建一筆並「存草稿」；另一個分頁改這筆；回到精靈再存草稿 → 409 對話框**有「重新載入這筆」**（以前沒有）。
